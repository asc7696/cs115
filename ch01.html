1-1 程式設計的概念｜程式語言與程式到底差在哪裡？

課本說明：程式（program）是一組用來指揮電腦工作的指令集合；而用來指揮電腦運作、具有特定格式的語言，稱為程式語言。也就是說，程式語言是「溝通的語言」，程式則是「使用這種語言寫出的指令集合」。

1-1.1 程式語言的功能｜比較低階與高階程式碼的樣態

課本將程式語言分成低階語言與高階語言。機器語言由 0 與 1 組成；組合語言使用較接近人類語言的字組；高階語言則更接近人類語言，例如 C、C++、Java、Python。

🔹 機器語言（低階語言）
01000100 110000 01100100
01000100 110001 01100100
由 0 與 1 組成，可直接由電腦硬體執行。
🔹 組合語言（低階語言）
MOV HP,10
ADD HP,5
SUB HP,2
用較接近人類的字組表示指令，仍與硬體關係密切。
🔸 高階語言
score = 10
print(score)

# Python
語法較接近人類語言，較容易閱讀與撰寫。

1-1.3 程式的語法與語意｜「寫法對」不代表「答案對」

課本將常見錯誤分成語法錯誤與語意錯誤：語法不正確時，程式無法正確翻譯或執行；語意錯誤則可能語法正確、程式也能執行，但結果與預期不同。課本以 print 拼字錯誤與梯形面積公式中的 + 誤寫為 - 說明。

例子 A：語法錯誤
primt("第1支Python程式")
無法依正確語法執行
print 拼字錯誤：正確應為 print(...)，這裡卻寫成 primt(...)。
例子 B：語意錯誤
a = 5 b = 10 c = 8 area = (a - b) * c / 2
程式可以執行，但計算邏輯錯誤
