🧠 競賽解題 SOP

  1. 看限制：N 到多少？先估計 O(N)、O(N log N)、O(N²)、O(2^N) 是否可行。
  2. 看結構：連續區間？圖？樹？選或不選？大量查詢？
  3. 先寫暴力：先知道最直覺的方法，再找 TLE 的瓶頸。
  4. 找重複工作：考慮 Prefix、DP、Hash、資料結構。
  5. 選演算法：把「題目特徵」對應到「演算法工具」。
  6. 分析複雜度：每一題寫完都要說出時間與空間複雜度。
  7. 測邊界：N=1、最小值、最大值、全部相同、答案不存在。
  8. 再 AC：ZeroJudge 通過後，寫一句「我為什麼這樣解」。

題目特徵 → 演算法

  • 連續區間 → Two Pointers / Sliding Window
  • 區間總和 → Prefix Sum
  • 大量區間修改 → Difference Array
  • 最少步數 → BFS
  • 連通 → DFS / BFS / DSU
  • 每個物品只能一次 → 0/1 Knapsack
  • N≤20、選／不選 → Bitmask
  • N 很大且狀態轉移固定 → Matrix Exponentiation
  • 大量 Query → Offline / BIT / Segment Tree / Mo

複雜度快速表

  • N≈10 → O(N!) 可能可行
  • N≈20 → O(2^N)
  • N≈100 → O(N³) 視常數
  • N≈1,000 → O(N²)
  • N≈100,000 → O(N log N) 或 O(N)
  • N≈10^9 → O(log N) 或數學 / 快速冪
